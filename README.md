# AI-Sharing · 我的 AI 分享资料

> 一个公开分享仓库：我自己在用的 AI skill、一套小白也能跟的开发流程，以及推荐的开源工具。
> **重心不是「工具」，是「流程 + 存档」**——这才是用 AI 做项目不失控的关键。

## 📂 目录

### 1. 我的 skill（自研）→ [`我的skill/`](./我的skill/)
- **[req](./我的skill/req.md)** — 需求澄清：把口语化、模糊的想法翻译成清晰、AI 能照着做的需求。解决「不知道怎么跟 AI 说清楚要做什么」。
- **[teach-friendly](./我的skill/teach-friendly.md)** — 大白话教学：先讲结论、原因与项目位置；只有贴切时才用比喻，不堆代码。解决「AI 的解释看不懂」。
- **[coding-standards](./我的skill/coding-standards.md)** — 通用代码编写守则：约束范围、安全、数据操作、测试与验证，避免 AI 开发时“能跑但不可靠”。

### 2. 开发流程 + 存档（核心）→ [`开发流程与存档/`](./开发流程与存档/)
- **[开发流程说明](./开发流程与存档/开发流程说明.md)** — 构思 → 写计划 → 执行 → 测试 → 验证 → 收尾，一条能跟的主线。
- **[plan 目录模板](./开发流程与存档/plan目录模板.md)** — 把每次开发 / 修复 / 重构存档，AI 和你都有据可查、不丢上下文。**这是最该学的一块。**
- **[通用代码编写守则](./开发流程与存档/通用代码编写守则.md)** — 不限语言或框架的编码底线：先确认范围、保护数据和密钥、最小化修改、写验证、留可追溯记录。

### 3. 推荐的开源 skill（锦上添花）→ [`推荐的开源skill/`](./推荐的开源skill/)
- 网页 PPT / 网页动画 / 文档生成 / 前端美化——让成品更好看的加分项（放链接，自行安装）。
